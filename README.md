# Which Flight Will Get You There Fastest? (FiveThirtyEight) — archival copy

A self-hosted, archival copy of FiveThirtyEight's flight-delays interactive
(2015, by Ritchie King), originally published at
`projects.fivethirtyeight.com/flights/`. FiveThirtyEight was shut down and its
project URLs no longer resolve; this copy was reconstructed from the Internet
Archive's Wayback Machine so the work remains usable, including the complete
original route dataset (BTS on-time data, twelve months ending September 2015).

I built this interactive at FiveThirtyEight; this copy is hosted as part of my
portfolio. All content © FiveThirtyEight/ABC News. Not affiliated with or
endorsed by FiveThirtyEight, ABC News, or Disney.

Changes from the original: analytics/tracking scripts removed, asset URLs made
local, and an attribution banner added.
